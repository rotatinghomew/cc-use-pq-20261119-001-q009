# 亚太合作项目分析服务

该服务帮助跨境合作协调团队跟踪企业、园区和产业伙伴之间的合作项目。项目可以涉及贸易、先进制造、数字服务、绿色能源、物流、医疗或农业；管理者可按领域、参与经济体和项目启动时间查看当前进展、阶段停留情况及已核实成果。

## 运行

需要 Python 3.11 或更新版本。依赖版本见 `requirements.txt`，在可联网的准备环境中安装后，可使用以下命令启动：

```sh
python -m pip install -r requirements.txt
PYTHONPATH=src uvicorn bridgeboard.api.app:app --host 127.0.0.1 --port 8000
```

默认数据库为当前目录下的 `bridgeboard.sqlite3`。可通过 `BRIDGEBOARD_DB` 指定其他 SQLite 文件。服务启动时创建所需表结构；请为数据库目录配置合适的访问权限，并定期备份。

## 使用方式

通过 `POST /projects` 登记合作项目，明确牵头经济体、合作经济体、行业、协调人、来源编号和启动日期。登记后，项目处于“线索发现”阶段。项目的进展通过 `POST /imports/events` 接收，事件由来源系统、来源记录编号和修订号识别；时间以带时区的 ISO 8601 值表达。一次事件导入要么整体通过，要么整体拒绝，响应会区分接收、重复和未通过的原因。

支持的进展包括伙伴匹配、可行性评估、签约、开始落地、成果核实、暂停、恢复和关闭。项目会按发生时间重建阶段；来源对旧事实提交更高修订号时，当前分析采用最新修订，旧版仍保留在本地记录中。已核实成果需关联成果类型及证据编号。暂停和关闭需提供原因。

主要接口：

- `GET /catalog` 返回支持的经济体、行业、阶段、事件类型及合法阶段来源，便于协调团队对齐数据口径。
- `GET /projects` 可按行业或参与经济体筛选项目；`GET /projects/{project_id}` 返回当前阶段。
- `GET /projects/{project_id}/history` 返回事件发生与接收时间、来源修订和所属导入批次。
- `GET /projects/{project_id}/history` 返回事件发生与接收时间、来源修订和所属导入批次。
- `GET /analytics/portfolio` 返回组合阶段数量、已核实成果比例、阶段停留与历史耗时，并支持按日期、行业或参与经济体筛选。
- `GET /analytics/sources` 展示各来源的事件到达延迟、重复送达和事实修订情况，帮助区分数据到达慢与项目推进慢。
- `GET /analytics/followups` 按阶段关注线、可行性受阻状态及暂停复核日期生成可解释的协调跟进清单。
- `GET /imports/batches/{batch_id}` 可回查一次导入的逐条处理结果。
- `GET /docs` 提供 FastAPI 生成的交互式接口说明。

## 指标解释

成果比例只在已关闭或成果已核实的项目中计算；尚未完成的项目不视为失败。没有合格分母时比例为空值。阶段耗时只使用已经结束的阶段区间，当前阶段显示为停留时长，暂停时间单独保留在时间线上。分组样本很少时，响应会提供提示，不应据此直接比较经济体或行业表现。报告的 `as_of` 日期用于固定停留天数口径，未传入时使用服务运行当天。

阶段漏斗统计项目曾经到达的阶段，不等同于当前阶段分布；暂停和关闭另行列示。来源质量指标依据已接收记录计算，不代表对合作伙伴的评级。事件迟到可能令项目业务阶段和组合分析随更正改变，来源报告用于解释这种变化，而不覆盖项目本身的业务事实。

阶段转移分析按相邻业务阶段事件统计实际转移和在前一阶段停留的时长。项目关闭只与其直接前一阶段关联，不将关闭原因推断成项目失败类型；没有发生过的转移不会被补成零样本。

启动月份的同期项目分析用于减少不同项目成熟度造成的误读，报告匹配耗时及成果耗时，同时提示小样本和未成熟批次。事件更正会同步影响阶段、耗时、漏斗和同期项目分析；历史接口保留当前有效版本标记，方便解释指标变化。

## 验证

在项目根目录执行：

```sh
PYTHONPATH=src python -m unittest discover -s tests -v
PYTHONPATH=src python -m compileall -q src
PYTHONPATH=src python -m bridgeboard.acceptance
```

验收程序使用临时数据库和本地合成合作案例，不访问新闻网站、外部账号或第三方数据服务。
